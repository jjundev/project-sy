## 1. 개요 및 목적
고등학교 수학 II(함수의 극한과 연속 등)를 학습하는 학생 서영이를 위해, 학교 유인물 및 선생님 필기 문제를 깔끔하게 정리하고 자율적인 문제 풀이가 가능하도록 1페이지당 4문제(2행 2열)와 전용 풀이 공간을 제공하는 A4 세로 규격의 HTML/CSS 기반 인쇄 템플릿과 데이터 파이프라인을 구축합니다.

- **용지 규격**: A4 세로 (210mm × 297mm)

## 3. 개별 문제 카드 컴포넌트 상세 (Card Component Anatomy)

각 문제 카드는 독립된 라운드 카드(`border: 1px solid #e2e8f0; border-radius: 6px;`)로 구성되며, 크기는 약 **91.5mm(가로) × 120.5mm(세로)**입니다.

### 세부 레이어 구성
1. **메타 헤더 (22px)**
   - **문제 번호**: 차콜 라운드 뱃지 (`[01]`, `[02]`)
   - **출처 태그**: `[학교 프린트 예제]`, `[선생님 필기 추가]`, `[AI 숫자 변형]` 등
   - **자가진단 체크**: 우측 상단 `○ △ ✕` 원형 기호 (맞음, 질문/애매함, 틀림)
2. **문제 제시부 (가변 높이, 약 25~35mm)**
   - 텍스트 폰트: 13.5px, 행간 1.6
   - 수식 렌더링: KaTeX 기반 고화질 인쇄 벡터 수식
   - 소문항 지원: (1), (2) 소문항 존재 시 가로 2단 분할 레이아웃 적용
3. **풀이 공간 (Flex: 1, 높이 약 60~70mm 확보)**
   - **5mm 은은한 도트 모눈 (Dot-grid)**: `radial-gradient(#cbd5e1 0.75px, transparent 0.75px)` 적용
   - 함수의 극한 단원 특성상 $xy$ 좌표평면 그래프 및 분수식 약분 풀이에 최적화
4. **하단 액션바 (24px)**
   - **좌측 팁/피드백 란**: 핵심 개념 힌트 (예: `💡 Tip: 0/0 꼴은 인수분해 후 약분`)
   - **우측 답안 기입란**: 직사각형 점선 테두리 `정답: [           ]`

## 4. 디자인 시스템 (Design System)

### 색상 팔레트 (흑백 인쇄 최적화)
- **주요 텍스트**: Pure Black (`#09090b`), Dark Charcoal (`#18181b`)
- **보조 메타 텍스트**: Slate Gray (`#64748b`)
- **카드 외곽선**: Slate Border (`#e2e8f0`)
- **도트 모눈**: Light Slate Dot (`#cbd5e1`) - 필기를 전혀 방해하지 않는 연한 채도

### 타이포그래피
- **한글 본문**: Pretendard, KoPubWorld돋움
- **수식 기호**: KaTeX Computer Modern Math Fonts
